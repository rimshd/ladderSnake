# Ladder & Snake (Vue 3)

A lightweight Ladder & Snake game built with Vue 3 and a single-page layout.

## How to run

Open `index.html` in your browser. No build tooling required.

If you prefer a local server (recommended for asset loading), run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Gameplay

- Roll the dice to move 1-6 squares.
- Land on ladders to climb up.
- Land on snakes to slide down.
- Reach square 100 to win.
